# ✨ Возможности

ForgeUpgrade добавляет на сервер полноценную систему развития предметов.

### Основные возможности

- ⚒️ **Собственный Стол улучшений** с интерфейсом кузнечного стола.
- 🟡 **Золотое улучшение** — `+10`.
- 🟢 **Изумрудное улучшение** — `+30`.
- 🔵 **Алмазное улучшение** — `+50`.
- 🟠 **Незеритовое улучшение** — `+70`.
- 🔴 **Армагеддон** — `+999999` к поддерживаемым характеристикам.
- 🛡️ Цветная отделка брони для каждого уровня.
- ✨ Отдельный эффект после каждого успешного улучшения.
- 🌈 Радужный магический эффект при успешном улучшении Армагеддона.
- ❤️ Регенерация здоровья от полного комплекта улучшенной брони.
- 🛡️ Дополнительная защита от скелетов, криперов, огня и утопления.
- ⛏️ Особые способности Армагеддона для **незеритовых** инструментов.
- ⚔️ Мгновенное убийство от незеритового оружия Армагеддона.
- 🧱 Возможность добывать **бедрок** киркой Армагеддона.

> ⚠️ Важно: обычные улучшения **не складываются**. Новое улучшение заменяет предыдущее.

# 🧱 Стол улучшений

Обычный кузнечный стол не становится Столом улучшений автоматически.

Нужно скрафтить специальный предмет **«Стол улучшений»**.

## 📜 Крафт Стола улучшений

```text
┌──────────┬──────────┬─────────────────────┐
│ Изумруд  │ Алмаз    │ Незеритовый слиток  │
├──────────┼──────────┼─────────────────────┤
│ Доски    │ Доски    │ Доски               │
├──────────┼──────────┼─────────────────────┤
│ Доски    │ Доски    │ Доски               │
└──────────┴──────────┴─────────────────────┘
```

Схема в верстаке:

```text
[💚][💎][⬛]
[🪵][🪵][🪵]
[🪵][🪵][🪵]
```

Подойдут **любые виды досок**.

После установки этот предмет становится настоящим **Столом улучшений ForgeUpgrade** и открывает интерфейс кузнечного стола.

# ⚒️ Как улучшать предметы

В Столе улучшений используются **3 входных слота**:

```text
┌─────────────────────────────────────────────────────────────┐
│ [ ШАБЛОН УЛУЧШЕНИЯ ] + [ ПРЕДМЕТ ] + [ МАТЕРИАЛ ] → РЕЗУЛЬТАТ │
└─────────────────────────────────────────────────────────────┘
```

### Пример

```text
[🟡 Золотое улучшение] + [⚔️ Меч] + [🟨 Золотой слиток]
                              ↓
                        [⚔️ Меч +10]
```

Для каждого уровня нужен **свой шаблон** и **соответствующий материал**.

| Улучшение | Шаблон | Материал в стол | Результат |
|---|---|---|---|
| 🟡 Золотое | Золотое улучшение | Золотой слиток | `+10` |
| 🟢 Изумрудное | Изумрудное улучшение | Изумруд | `+30` |
| 🔵 Алмазное | Алмазное улучшение | Алмаз | `+50` |
| 🟠 Незеритовое | Незеритовое улучшение | Незеритовый слиток | `+70` |
| 🔴 Армагеддон | Армагеддон | Звезда Незера | `+999999` |

### ❗ Важно

Каждая операция расходует:

- 1 × шаблон улучшения;
- 1 × улучшаемый предмет;
- 1 × соответствующий материал.

Вместо двух предметов в результате создаётся **один уже улучшенный предмет**.

| Уровень | Бонус | Материал | Цвет брони | Эффект успеха |
|---|---:|---|---|---|
| 🟡 Золотое | `+10` | Золотой слиток | 🟡 Золотой | Золотое свечение |
| 🟢 Изумрудное | `+30` | Изумруд | 🟢 Изумрудный | Зелёный эффект |
| 🔵 Алмазное | `+50` | Алмаз | 🔵 Голубой | Алмазное сияние |
| 🟠 Незеритовое | `+70` | Незеритовый слиток | 🟠 Медно-оранжевый | Огненный эффект |
| 🔴 Армагеддон | `+999999` | Звезда Незера | 🔴 Красный | 🌈 Радужная магия |

## Как работают уровни

```text
Обычный предмет
      │
      ├── 🟡 Золотое       → +10
      ├── 🟢 Изумрудное    → +30
      ├── 🔵 Алмазное      → +50
      ├── 🟠 Незеритовое   → +70
      └── 🔴 Армагеддон    → +999999
```

Новое улучшение **заменяет старое**, а не складывается с ним.

❌ Неправильно:

```text
+10 + +30 + +50 = +90
```

✅ Правильно:

```text
Предмет с Алмазным улучшением = +50
```

# 🔴 Армагеддон — +999999

> ☠️ Самое мощное улучшение ForgeUpgrade.

Армагеддон добавляет **`+999999` к поддерживаемым характеристикам**.

Для брони также усиливаются:

- 🛡️ броня;
- 🧱 прочность брони;
- 💨 сопротивление отбрасыванию;
- ❤️ максимальное здоровье.

Для оружия и поддерживаемых инструментов усиливаются боевые характеристики.

## ⚠️ Главное правило Армагеддона

**Дополнительные сверхспособности Армагеддона доступны только незеритовым предметам.**

```text
Обычный / золотой / железный / алмазный предмет + Армагеддон
→ получает только бонус +999999 к характеристикам

Незеритовый предмет + Армагеддон
→ +999999 к характеристикам
→ + уникальные способности Армагеддона
```

# 🛡️ Способности брони

## ❤️ Восстановление здоровья

Регенерация работает только при надетом **полном комплекте из 4 улучшенных частей брони**:

```text
[Шлем] + [Нагрудник] + [Поножи] + [Ботинки]
```

Все четыре части должны иметь одно из улучшений ForgeUpgrade:

- Золотое;
- Изумрудное;
- Алмазное;
- Незеритовое;
- Армагеддон.

Если снять **хотя бы одну часть**, эффект регенерации снимается сразу.

> ❤️ Для полного незеритового комплекта Армагеддона дополнительно выполняется автоматическое восстановление здоровья до максимального значения.

# ☠️ Армагеддон: незеритовая броня

Дополнительные способности действуют только на **незеритовых частях брони с улучшением Армагеддон**.

## 🪖 Шлем

👁️ Постоянное ночное зрение.

Эффект обновляется стабильно и снимается при снятии шлема.

## 🛡️ Нагрудник

🪽 Возможность летать.

При снятии нагрудника способность, выданная плагином, отключается.

## 👖 Поножи

- 🔥 иммунитет к огню и лаве;
- 🌊 восстановление воздуха под водой.

## 👢 Ботинки

- 🦘 усиленный прыжок;
- 💨 дополнительная скорость.

## 👑 Полный комплект Армагеддона

```text
🪖 + 🛡️ + 👖 + 👢
```

Полный незеритовый комплект Армагеддона автоматически восстанавливает здоровье игрока до его текущего максимального значения.

# ⛏️ Незеритовые инструменты Армагеддона

## ⛏️ Кирка

Кирка Армагеддона:

- ломает блоки с одного удара;
- ломает **2 блока подряд** по направлению игрока;
- способна разрушить даже **BEDROCK**;
- добытый бедрок добавляется прямо в инвентарь;
- если инвентарь заполнен — бедрок выпадает рядом и не исчезает.

```text
⛏️ → [БЛОК][БЛОК]
```

## 🪓 Топор

Топор Армагеддона мгновенно ломает целевой блок с одного удара.

## 🧹 Лопата

Лопата Армагеддона ломает **3 блока подряд** по направлению игрока.

```text
🧹 → [БЛОК][БЛОК][БЛОК]
```

## 🌱 Мотыга

Незеритовая мотыга Армагеддона:

- обрабатывает сразу **3 блока земли**;
- создаёт три грядки за одно использование;
- ускоряет рост растений рядом с новыми грядками.

```text
[ГРЯДКА][ГРЯДКА][ГРЯДКА]
```

# 🚀 Установка

1. Скачайте собранный `ForgeUpgrade.jar`.
2. Поместите файл в папку:

```text
plugins/
```

3. Запустите сервер.
4. После запуска ForgeUpgrade зарегистрирует рецепты и создаст рабочие данные.
5. Скрафтите **Стол улучшений**.
6. Скрафтите нужный шаблон улучшения.
7. Улучшайте оружие, инструменты и броню.

---

# 🗂️ Файлы плагина

После запуска используются ресурсы плагина:

```text
plugins/ForgeUpgrade/
```

Основные файлы проекта:

- `config.yml` — общие настройки;
- `messages.yml` — игровые сообщения;
- `upgrades.yml` — данные улучшений;
- `upgrade-tables.yml` — сохранённые установленные Столы улучшений.

---

# ⚙️ Техническая информация

- Улучшение хранится непосредственно внутри предмета через постоянные данные.
- Характеристики применяются через реальные модификаторы атрибутов.
- При новом улучшении старые модификаторы ForgeUpgrade удаляются и заменяются новыми.
- Улучшенный предмет сохраняет свой тип улучшения после перезапуска сервера.
- Способности брони проверяются во время игры и снимаются при снятии нужной части.
- Армагеддон на не-незеритовых предметах даёт только основной бонус `+999999`, без уникальных способностей незеритового Армагеддона.
